# 1. はじめに

[目次](../README.md) | 次: [使い始める](02-getting-started.md)

## 1.1 Clysm UI とは

Clysm UI は、Common Lisp だけで GUI アプリケーションを書くためのフレームワークです。プログラムは Clysm によって WebAssembly にコンパイルされ、ブラウザのページとして、または Electron を使ったデスクトップアプリケーションとして動きます。JavaScript や HTML を書く必要はありません（ページの雛形はツールが作ります）。

```lisp
(define-interface greeter ()
  ()
  (:panes
   (name text-input-pane :placeholder "名前")
   (message title-pane
            :text (computed (format nil "こんにちは、~A さん"
                                    (text-input-pane-text name)))))
  (:default-initargs :title "あいさつ"))

(display (make-instance 'greeter))
```

この例では、名前の欄に入力するたびにメッセージが変わります。画面を更新するコードはどこにもありません。メッセージの文字列が「名前の欄の内容から計算される値」として書かれているので、欄が変わるとメッセージも変わります。

## 1.2 設計の考え方

### 状態が画面を決める

アプリケーションの状態は、普通の CLOS オブジェクトのスロットと変数にあります。画面はその状態から計算されます。状態を `setf` で変えると、それを読んでいた部分だけが描き直されます。「ボタンの文字を変える」は `(setf (button-text button) "停止")` です。

この仕組みは、ペイン（ボタンや欄）自身にも、アプリケーションのモデルにも同じように働きます。

### 3つの層

フレームワークは3つの層からなります。上の層は下の層の上に作られていて、どの層も直接使えます。

| 層 | 参考にしたもの | 主な機能 |
|---|---|---|
| ペインとインターフェース | CAPI | `define-interface`、ボタン・リスト・表などの部品、レイアウト、メニュー、ダイアログ、描画 |
| プレゼンテーションとコマンド | CLIM | 画面上のオブジェクト、型付きの引数を持つコマンド、ストリームペイン、インタラクタ |
| コンポーネントとマークアップ | React などの UI ライブラリ | S 式で書くマークアップ、状態を観測して差分だけを描き直す仕組み |

ふつうのアプリケーションは、上の2つの層で書きます。新しい種類のペインを作るときや、HTML の要素を直接並べたいときに、下の層を使います。

### バックエンド

画面への描画は、十数個の総称関数からなるプロトコルを通して行います。実装は3つあります。

- **DOM バックエンド**（`ui/dom.lisp`）: ブラウザのページに描きます。
- **デスクトップバックエンド**（`ui/desktop.lisp`）: Electron の中で動くときに使われます。DOM バックエンドに、ネイティブのメニューバー、ダイアログ、ファイルの読み書きを加えたものです。
- **S 式バックエンド**（`ui/sexp.lisp`）: 画面を S 式の木として作ります。ブラウザなしでテストするためのものです。

同じプログラムが、ブラウザでもデスクトップでもテストでも動きます。

## 1.3 CAPI・CLIM を知っている人へ

名前と考え方の多くは CAPI と CLIM から借りています。主な違いは次のとおりです。

- **待てない**: ページの中では、関数の途中でユーザーの操作を待つことができません。そのため `prompt-for-string` などのダイアログはすぐに戻り、答えを `:continuation` の関数に渡します。ただし、エラーのリスタートを選ぶダイアログと型付きコマンドの引数は、その場で待つように見える形で使えます。
- **ピクセルではなく図形**: `output-pane` の描画は SVG の図形の木になります。描き直しは差分で行われ、図形一つひとつをプレゼンテーション（クリックできるオブジェクト）にできます。
- **見た目は CSS**: 色やフォント、余白は `ui/ui.css` で決まり、CSS のカスタムプロパティで変えられます。

対応関係の一覧は [付録](17-capi-and-clim.md) にあります。

## 1.4 ファイルの構成

フレームワークは `ui/` にあり、アプリケーションと一緒にコンパイルします。

| ファイル | 内容 |
|---|---|
| `ui/ui.lisp` | パッケージ `UI`、マークアップ、コンポーネント、モデル、バックエンドのプロトコル |
| `ui/command.lisp` | コマンド、メニュー項目 |
| `ui/present.lisp` | プレゼンテーション、ポップアップメニュー、`accept` |
| `ui/pane.lisp` | ペイン、レイアウト、メニュー、インターフェース、ウィンドウ |
| `ui/dialog.lisp` | ダイアログ、ファイル、クリップボード、エラーの表示 |
| `ui/graphics.lisp` | `output-pane` と描画関数、`graph-pane` |
| `ui/stream.lisp` | ストリームペイン、インタラクタ |
| `ui/dom.lisp` | DOM バックエンド |
| `ui/desktop.lisp` | デスクトップバックエンド |
| `ui/sexp.lisp` | S 式バックエンド |
| `ui/dev.lisp` | 開発用イメージの設定 |
| `ui/ui.css` | 見た目 |
| `ui/electron/` | デスクトップアプリケーションの殻（Electron） |

例は `examples/todo/`（TODO リスト）と `examples/contacts/`（アドレス帳）にあります。アドレス帳は、このマニュアルで説明するほとんどの機能を使っています。
